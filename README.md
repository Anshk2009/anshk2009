### 📌 Things I learned the hard way

> Tightening a Content-Security-Policy silently killed the 3D hero on my landing
> page. The page still returned 200, the script still loaded, the scene still
> downloaded — nothing went red. A human noticing an empty space is what caught it.

> A SQL file headed *"safe to re-run"* would have dropped every user table. That
> comment was true the day it was written and nobody re-read it once there was
> real data.

Both are in [EconIntel's commit history](https://github.com/Anshk2009/Econintel/commits/main),
written up properly. I'd rather leave the reasoning behind than a clean-looking log.
